I am a cybersecurity graduate (MSc, Politecnico di Torino, 2026) working on **LLM-based agents for software security**. I am currently an LLM developer at the [University of Southern Denmark (SDU)](https://www.sdu.dk/en), where I designed and implemented a retrieval-augmented generation (RAG) system that helps university employees work with scanned documents. I also teach the exercise sessions of SDU's Bachelor-level Web Development course.

For my Master's thesis, carried out at SDU, I built a multi-agent LLM system that works alongside the static analysis tool CodeQL: it checks CodeQL's results, finds gaps in its rules and drafts new ones. As a research assistant at SDU, I then co-developed, with two software companies, an AI system in which LLM agents find security vulnerabilities in source code, explain how they could be exploited and propose fixes.

Research interests
======
* Evaluating, verifying and monitoring the behaviour of LLM agents
* Security of LLM-based systems
* Benchmarks and evaluation methods that make agent failures measurable
* LLMs for software security and vulnerability detection
